# Project Title
Automatic-Fan-Speed-Controller-using-Ambient-Temperature


## Description
The Automatic Fan Speed Control Using Ambient Temperature project is a smart temperature-based cooling system designed to automatically adjust the speed of a fan according to the surrounding temperature. The system uses a temperature sensor to continuously monitor ambient temperature and a microcontroller to control the fan speed using PWM (Pulse Width Modulation) techniques.

As the temperature increases, the fan speed automatically increases to provide better cooling, and when the temperature decreases, the fan speed reduces to save energy. This system improves energy efficiency, reduces manual operation, and provides automatic environmental control for homes, offices, and industrial applications.

## Components Used
Arduino UNO / ESP-based Microcontroller
Temperature Sensor (DHT11, LM35, or DS18B20)
DC Fan / Cooling Fan
STMicroelectronics L298N Motor Driver Module or MOSFET Driver
LCD/I2C Display (optional)
Power Supply (12V Adapter/Battery)
Connecting Wires and Breadboard
Resistors and Transistors (if required)

## Features
Automatic fan speed adjustment based on temperature
Real-time ambient temperature monitoring
PWM-based smooth speed control
Energy-efficient cooling system
Reduced manual intervention
Compact and low-cost design
